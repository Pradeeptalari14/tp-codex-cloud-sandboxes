# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately by contacting Pradeep Talari or opening a confidential security advisory on GitHub.

Please include:
- Description of the vulnerability.
- Steps to reproduce.
- Potential impact and affected components.
